# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive. Harassment or exclusionary behaviour of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainers via a
[GitHub security advisory](https://github.com/gregamano3/hris_attendance_payroll/security/advisories/new)
or by contacting [@gregamano3](https://github.com/gregamano3). All reports will be reviewed and handled confidentially.
